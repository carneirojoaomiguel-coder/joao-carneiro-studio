Ajuda

Como obter o token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token.

Dá acesso apenas ao repositório joao-carneiro-site e permissão Contents: Read and write.

Depois cola o token aqui. Quando guardares uma obra, o GitHub atualiza os ficheiros e o Netlify publica automaticamente.

Não publiques o token em lado nenhum. Ele fica só no teu browser se clicares em “Guardar token”.
